## About Me

Security engineer in the making, driven by one question: **how do we trust the hardware we build on?**

With a dual background in **software systems** (42 Mulhouse, Korea University) and **brain & cognitive sciences**, I'm working toward becoming an **embedded systems security expert** — focused on hardware-layer vulnerabilities, automotive and industrial protocols (CAN Bus, UART, Modbus), and secure firmware design (ISO 21434 / AUTOSAR SecOC).

I'm currently building that expertise on two fronts through a work-study program (alternance): hands-on **product security** at **Legrand**, where I work on the security and compliance of connected products (GRC, ISO 27001, CRA), and the **Cyber Security Expert Master's at OTERIA**, specializing in OT & IoT security, from PLC/SCADA pentesting to firmware defense.

Alongside, I build my own security projects on real hardware — attacking and defending embedded systems from the silicon up.
